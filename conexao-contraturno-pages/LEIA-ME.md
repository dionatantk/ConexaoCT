# Conexão Contraturno — teste visual

Este diretório contém uma prévia estática do site, sem banco de dados, sem autenticação real e sem fotos ou dados pessoais persistidos.

## Publicar gratuitamente no GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie o arquivo `index.html` deste diretório para a raiz do repositório.
3. Em **Settings → Pages**, escolha **Deploy from a branch**, selecione `main` e a pasta `/ (root)`.
4. Salve. O GitHub Pages publicará o protótipo em um endereço `https://<seu-usuario>.github.io/<repositorio>/`.

O protótipo ficará público e qualquer pessoa poderá abrir a página. A tela de login é apenas visual e aceita qualquer texto; ela não restringe o acesso. Não inclua usuários, fotos reais ou informações da escola nesta prévia.
